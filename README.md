# Unemployment Analysis in India

## CodeAlpha Data Science Internship — Task 2

### Overview

This project analyzes unemployment trends in India using Python and two unemployment datasets.

The analysis covers:
- Monthly unemployment trends
- Regional unemployment differences
- COVID-19 period impact
- Labour participation trends
- Estimated employment trends
- Geographical unemployment patterns
- Correlation between key employment indicators

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The project uses two unemployment datasets:

1. `Unemployment in India.csv`
2. `Unemployment_Rate_upto_11_2020.csv`

The first dataset is used for the main time-series, regional, employment, labour participation, and COVID-period analysis. The second provides additional geographical information for regional analysis.

## Key Findings

- The pre-COVID average unemployment rate was **9.51%**.
- The average unemployment rate during April–May 2020 increased to **24.26%**.
- Estimated employment declined by **31.06%** between March and April 2020.
- Labour participation declined from **43.08%** in March 2020 to **35.14%** in April 2020.
- Unemployment rates showed substantial variation across regions and geographical zones.
